## 主打项目

### 🚜 [smart-agri-machinery](https://github.com/jhy1238/smart-agri-machinery) · 智能农机无人作业系统软件原型

感知定位 → 全覆盖规划 → 多机调度 → 跟踪控制 → 云端遥测，一条命令跑通全链路，**103 项数值断言**守住指标。

| 环节 | 关键结果 |
|---|---|
| GNSS/RTK + IMU 组合定位（EKF） | 全程 RMS **1.98 cm**，RTK 固定解 **0.68 cm**，丢星 6.2 s 内航位推算 |
| 牛耕式全覆盖 + Dubins Π/Ω 地头转弯 | 平均覆盖率 **99.72%**、重叠率 **9.9%**、非作业里程占比 **8.97%** |
| 纯跟踪控制 + 曲率/转向速率约束速度规划 | 横向误差 RMS **2.15 cm**、航向误差 **0.63°** |
| 多机协同调度（贪心 + Or-opt/2-opt） | 较轮询基线完工 **−15.5%**、空驶里程 **−10.9%** |
| J1939/ISOBUS 遥测 + 3σ/EWMA 异常检测 | 故障检出率 **100%**、平均时延 **2.3 s** |

`Node.js ESM` `EKF` `Dubins` `Pure Pursuit` `J1939 / ISOBUS` `零第三方依赖`

### 🌱 [weed-vision-prescription](https://github.com/jhy1238/weed-vision-prescription) · 田间杂草识别与变量喷施处方图

低成本可见光影像 → 杂草密度栅格 → 三级处方图，把"全幅均一喷施"改成"按草量喷施"。

- ExG 植被指数 + Otsu 自适应阈值分割：IoU **0.877**
- 作物行自动检测：16 行、行距估计偏差 **0.46 cm**
- 连通域特征分类 → 1 m × 1 m 密度栅格 → 分区喷施处方图，省药 **45.9%**
- `node src/demo.mjs --check` 5 项自检复现全部指标

`Node.js` `ExG` `Otsu` `形态学` `连通域` `处方图`

## 关于数据口径

两个仓库里的指标**全部是仿真 / 软件在环结果**（合成地块、合成农田影像、合成 CAN 报文），
不是田间实测数据。复现命令、随机种子、断言位置都写在
[docs/12_指标复现与数据溯源](https://github.com/jhy1238/smart-agri-machinery/blob/main/docs/12_指标复现与数据溯源.md) 里，
也明确写了方法的边界（比如行内杂草召回仅 ≈0.11，单目 RGB 下颜色法无法区分）。

宁可把局限写清楚，也不把仿真说成实车验证。
